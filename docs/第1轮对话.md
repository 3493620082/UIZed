## 学习内容概览

### 1. PZ-UI_API 库（第三方 UI 封装库）
这是一个对游戏原生 UI 的简化封装，所有元素都是原生元素（按钮继承 `ISButton`、窗口派生自 `ISCollapsableWindow`）。

**创建 UI 的流程**：
1. `NewUI()` 创建窗口
2. `UI:addXXX()` 按行添加元素
3. `UI:nextLine()` 换行
4. 全部完成后 `UI:saveLayout()`

**支持的元素**（`addXXX` 方法）：
- `addText`（文本，4种字体、3种位置）
- `addRichText`（富文本，支持 `<H1>`、`<SIZE:small>`、`<LINE>`、`<RGB:r,g,b>` 等标签）
- `addProgressBar`（进度条）
- `addButton`（按钮，点击回调 `func(button, args)`）
- `addTickBox`（复选框）
- `addEntry`（输入框）
- `addComboBox`（下拉框）
- `addScrollList`（滚动列表）
- `addImage` / `addImageButton`（图片）
- `addEmpty`（占位）

**关键约定**：
- 元素可用 `UI["name"]` 访问；命名建议带数字避免冲突
- 坐标：x/y 为左上角，尺寸可用百分比（屏幕的 0-1）或像素
- UI 级函数：`open/close/toggle`、`setPositionPercent`、`setTitle`、`nextLine`、`isSubUIOf`、`setCollapse` 等

### 2. PZwiki 原生 UI 系统
**文件结构**：UI 应放 `media/lua/client/YourMod/` 下，建议一个文件一个 UI 类。

**原生创建方式**（`ISPanel:derive` 派生类）：
- 必须实现 `initialise`（加子元素）、`prerender`、`render`、`new` 方法
- `ISPanel.new()` 创建实例，`initialise()` 初始化，`addToUIManager()` 显示

**添加子元素**：使用 `self:addChild(ISLabel:new(...))` / `ISButton:new(...)`，比在 render 里手动调用 `drawText` 更高效。

**外观控制**：直接改 `backgroundColor` 和 `borderColor` 表。

**面板替代选项**：`ISPanelJoypad`（手柄支持）、`ISCollapsableWindow`（可折叠窗口）。

**ISUIElement 绘制函数**：`drawText`、`drawRect`、`drawRectBorder`、`drawTextureScaled`、`drawProgressBar` 等。

**工具函数**：`getCore():getScreenWidth()`、`getMouseX()`、`isCtrlKeyDown()` 等。
