# 控件事件列表

控件可绑定自定义函数（回调）的事件接口汇总。

## 按钮（Button）

**事件**：点击

**绑定方式**：
```lua
-- 添加时直接传入回调函数
UI:addButton("button1", "确定", onClick)

-- 添加后运行时修改回调
UI["button1"]:setOnClick(onClick)
```

**回调签名**：
```lua
function onClick(button, args)
    -- button: 按钮元素自身
    -- args:   附加参数表（通过 addArg 添加）
end
```

**附加参数**：
```lua
UI["button1"]:addArg("index", 1)
-- 回调中通过 args.index 取值
```

## 图片按钮（ImageButton）

**事件**：点击

**绑定方式**：
```lua
-- 添加时直接传入回调函数
UI:addImageButton("ibutton1", "media/ui/myImage.png", onClick)

-- 添加后运行时修改回调
UI["ibutton1"]:setOnClick(onClick)
```

**回调签名**：
```lua
function onClick(button, args)
    -- button: 图片按钮元素自身
    -- args:   附加参数表（通过 addArg 添加）
end
```

**附加参数**：
```lua
UI["ibutton1"]:addArg("index", 1)
-- 回调中通过 args.index 取值
```

## 输入框（Entry）

**事件**：回车（在输入框内按下 Enter）

**绑定方式**：
```lua
UI:addEntry("entry1", "", false)
UI["entry1"]:setEnterFunc(onEnter)
```

**回调签名**：
```lua
function onEnter(element, text, args)
    -- element: 输入框元素自身
    -- text:    输入框当前的文本
    -- args:    附加参数表（通过 addArg 添加）
end
```

**附加参数**：
```lua
UI["entry1"]:addArg("name", "value")
-- 回调中通过 args.name 取值
```

## 滚动列表（ScrollList）

**事件**：鼠标点击列表项

**绑定方式**：
```lua
UI:addScrollList("scroll1", {"item 1", "item 2", "item 3"})
UI["scroll1"]:setOnMouseDownFunction(_, onItemClick)
```

**回调签名**：
```lua
function onItemClick(_, item)
    -- _:   滚动列表元素自身
    -- item: 被点击的列表项
end
```

## 事件范围约定

| 控件 | 事件 | 绑定方法 |
|---|---|---|
| 按钮 | 点击 | `addButton(name, text, func)` / `setOnClick(func)` |
| 图片按钮 | 点击 | `addImageButton(name, path, func)` / `setOnClick(func)` |
| 输入框 | 回车 | `setEnterFunc(func)` |
| 滚动列表 | 鼠标点击列表项 | `setOnMouseDownFunction(_, func)` |
